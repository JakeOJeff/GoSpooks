

# Structure

## Guide

- Enter House
- Enter Hallway from Patio [ NO KEY ]
- Pickup Silver Key in Hallway
- Hallway to (WEST) Kitchen
- Pickup Magic Driller in Kitchen
- Kitchen to (EAST) Hallway
- Hallway to (EAST) [UNLOCK - Silver Key] Library
- Library to (NORTH) [BREAK - Magic Driller] Vault
- Pickup Green Key in Vault
- Vault to (SOUTH) Library
- Library to (WEST) Hallway
- Hallway to (WEST) Kitchen
- Kitchen to (NORTH) [UNLOCK - Green Key] Storage
- Pickup Golden Key in Storage
- Storage to (SOUTH) Kitchen
- Kitchen to (EAST) Hallway
- Hallway to (EAST) Library
- Library to (NORTH) Vault
- Vault to (DOWN) [UNLOCK - Golden Key] Basement
- Pickup Red Key in Basement
- Basement to (UP) Vault
- Vault to (SOUTH) Library
- Library to (WEST) Hallway
- Hallway to (NORTH) [UNLOCK - Red Jey] Bedroom
- Pickup Gold Coin in Bedroom
- Bedroom to (SOUTH) Hallway
- Hallway to (EAST) Library
- Library to (NORTH) Vault
- Vault to (DOWN) Basement
- Basement to (SOUTH) [UNLOCK - Gold Coin ] Cracked
- Pickup Attic Key in Cracked
- Cracked to (NORTH) Basement
- Basement to (UP) Vault
- Vault to (SOUTH) Library
- Library to (WEST) Hallway
- Hallway to (UP) [UNLOCK - Attic Key] Attic
- Pickup Electric Chainsaw in Attic
- Attic to (DOWN) Hallway
- Hallway to (EAST) Library
- Library to (NORTH) Vault
- Vault to (DOWN) Basement
- Basement to (SOUTH) Cracked
- Cracked to (SOUTH) [CUT - Electric Chainsaw] Grain
- Pickup White Key in Grain
- Grain to (NORTH) Cracked
- Cracked to (NORTH) Basement
- Basement to (UP) Vault
- Vault to (SOUTH) Library
- Library to (WEST) Hallway
- Hallway to (SOUTH) [UNLOCK - White Key] Patio
- WIN
